# Gym Members Report | Power BI Dashboard

## Project Summary
Developed an interactive Power BI dashboard to analyze gym members' fitness and workout data, providing insights into workout patterns, calories burned, BMI, heart rate, hydration, and member demographics.

## Key Features
- Workout analysis across Strength, Cardio, Yoga, and HIIT
- Experience-level filtering using interactive slicers
- Calorie burn and workout duration analysis
- Gender-wise age comparison
- BMI, Body Fat, Weight, Hydration, and Heart Rate analysis
- Interactive KPI cards and visualizations

## Key Insights
- Strength Training showed the highest participation.
- Longer workout sessions resulted in higher calorie burn.
- Average member age was around 38–39 years.
- Experience level showed differences in cardiovascular metrics.
- BMI remained relatively consistent across workout types.

## Tools & Technologies
**Power BI | Power Query | DAX | Excel | Data Visualization**

## Business Value
The dashboard helps fitness managers monitor member performance, identify workout trends, and support data-driven decisions for better member engagement and retention.
